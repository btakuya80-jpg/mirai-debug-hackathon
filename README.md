# 未来デバッグ（Mirai Debug）

**入社する前に、その会社での将来を試運転する。**

求職者の分身と、仮想の会社・上司・同僚を AI でつくり、
1か月後／3か月後／1年後／3年後／10年後にどうなるかを何度も試走します（＝キャリアのデバッグ）。

Built with Claude: Japan 2026 の提出作品です。

| URL | 案 | 狙い |
|---|---|---|
| `/` | 入口 | 3案への入り口と、答え合わせ（「当たるのか？」）の要約 |
| `/a` | A案 デバッガー画面風 | 人生を「実行」し、1か月後・1年後などのブレークポイントで止めて調べる。辞めたくなる場面は赤い警告、分かれ道はブランチ（枝分かれ）の図 |
| `/b` | B案 10年の山 | 8つの力を山並みで見せる。時点を進めると山が育ち、毎日の小さな差が10年で大きな山になる |
| `/c` | C案 ゲームのセーブ画面風 | 分身をオリジナルのドット絵キャラにし、時点ごとのセーブデータを行き来してステータスの変化を見る |

## 画面の流れ（3案共通・求職者側）

1. 求人ページ（架空）→「入社後を試運転する」
2. 入力：選ぶだけの10問＋住むエリア
3. 会社を選ぶ：架空の2社（仮想 あおば社／仮想 みどり物流）
4. 試走中：5本の試走と、時点ごとの進み具合
5. 結果：時点ごとの出来事と分身の動き／能力表（8項目・S〜G）と理由／辞めたくなる度合い（高・中・低）と理由／分かれ道（1本は違う業界へ移る筋）／上司あり・なしの比べ表示／面接で確かめる質問
6. 2社に入った場合の比べ表示

各段階は URL の `#job` `#input` `#company` `#run` `#result` `#compare` で直接開けます（例：`/b#result`）。
デモ動画を撮る時は `?demo` を付けると、右下の説明窓（ⓘ）が出ません（例：`/a?demo#run`）。

## 守っていること

- 企業に合否・点数・％を出さない。「予測」ではなく「シナリオ（筋書き）」として見せる。
- 辞めたくなる度合いは「高・中・低」の3段階だけ。
- 能力表は人の格付けではなく、本人が選んだ目標にどこまで近づいたかとして出す。
- 実在の人名・会社名は使わない（すべて架空）。他社のゲーム作品名・キャラクターも使わない。
- 企業側の入力画面は今回は作らない（会社データは JSON で用意）。

## 公開ページ（Artifact）で見る

PC に Node が無くても見られるよう、各案を HTML に書き出して claude.ai の Artifact で公開しています。
**1つのURLにまとめてあり、入口から A・B・C の3案へ進めます。**

https://claude.ai/artifact/K6R6pgL3hXhuYGpPqUJzyj

（他の人に見せる時は、Artifact の「共有」から共有してください）

公開ページでは `?` が渡らないので、デモ撮影は `#demo-result` のように `demo-` を付けた段階名で開くと、説明窓（ⓘ）が出ません。

書き出し方：

```bash
npm install
node scripts/build-standalone.mjs --one   # → dist-one/index.html（入口）＋ a.html b.html c.html を1つの Artifact に
node scripts/build-standalone.mjs         # → dist-standalone/ に各案を別々のページとして
```

React は cdnjs の UMD 版を読み込み、画面のコード・CSS・見本データは HTML の中に入れています。公開ページどうしのリンク先は `standalone/links.json` に書きます。

## 動かし方

Node.js 20.9 以上が必要です。

```bash
npm install
npm run dev
# → http://localhost:3000 を開く（/a /b /c）
```

本番と同じ形で確かめる時：

```bash
npm run build
npm start
```

## 作り

- Next.js 16（App Router）＋ TypeScript ＋ Tailwind CSS 4
- `src/data/mirai.json` … 3案共通の見本データ（求人・10問・2社・5本の試走・時点ごとの結果・分かれ道・比べ表示）
- `src/lib/mirai.ts` … 画面の流れと入力の状態（3案共通）
- `src/app/a` `src/app/b` `src/app/c` … 各案の画面
- `src/components/InfoWindow.tsx` … 説明窓（ⓘ）。この画面／項目の理由／機能一覧／メモ。項目を押すと画面の該当部分が光る
