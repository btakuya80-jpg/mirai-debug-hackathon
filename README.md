# 未来デバッグ（Mirai Debug）

**入社する前に、その会社での将来を試運転する。**

求職者の分身と、仮想の会社・上司・同僚を AI でつくり、
1か月後／3か月後／1年後／3年後／10年後にどうなるかを何度も試走します（＝キャリアのデバッグ）。

Built with Claude: Japan 2026 の提出作品です。

---

## いまの状態（2026-11-06・G案に一本化）

- 作り込みは **G案だけ** で進めます（`/g`、単体ページは `node scripts/build-standalone.mjs --g` → `dist-g/index.html`）。A〜J案のコードと入口ページは消さずに残しています。
- 画面の頭と結果の画面に「これは試走したシナリオの一つで、未来を約束するものではありません」を必ず出します。
- 出さない物：実名・実在の会社名／点数・％・合否／API キー／保険・借入などのお金の提案／広告枠。登場する会社・人物はすべて架空です。

### Claude のつなぎ方（API キーを持たない）

- 公開した Artifact の **`sample` 機能** で Claude を呼びます（`window.claude.use("sample")` → `sample.json(prompt)`）。見る人の Claude のアカウントで動き、最初の1回だけ見る人に許可を聞きます。コードにもサーバーにもキーはありません。Vercel も使いません。
- 呼ぶのは **1回だけ**。求人の本文を渡し、決まった形の JSON（会社まとめ・身につく専門知識・6本の道の判定・入社1年の場面・分かれ道の様子・道ごとの場面・次に確かめること）を返させます。形は `src/lib/ai.ts` の `buildPrompt` に書いてあります。
- ページからは外のサイトを読めないため、**見本の求人URL**は用意した架空の求人本文を、**それ以外のURL**は求人の本文を貼ってもらって Claude に渡します。
- 読めない項目は埋めずに「不明」と出します。求人に無い想定（AIスキルなど）は「仮定」と出します。
- Claude を使えない時（Artifact の外・許可されない・混雑・形が崩れた JSON）は、**見本データで続け**、会社まとめの画面に理由を出します。
- 返ってきた JSON は `registerAiRead` で確かめてから画面のデータにします（Lv は 0〜4 に丸め、場面ごとに1つずつ上がるようにそろえる）。

### G案に入れたもの（11/6）

| 項目 | 中身 | 主なファイル |
|---|---|---|
| 年数の切り替え | 分かれ道が来る時点を 1年・3年（初期）・5年で選ぶ。1年＝知った・できる、3年＝任される、5年＝教えられる。年数だけで一律に上げず、会社と職種で差をつける | `src/lib/know.ts` `src/lib/life.ts` `src/lib/years.ts` |
| 感情ゲージ | 上司・同僚・相手の気持ちを、顔＋一言＋3つの印で出す（点数・％なし、仮想の人物だけ） | `PackApp.tsx` の `FeelBox` |
| AIスキル | 専門知識の1つ「AIの答えを確かめて使う」。求人に無い時は「仮定」 | `src/lib/know.ts` |
| 人生の出来事のマス | 年表に出会い・交際・結婚・家族のマスを足す。結婚する・しない・まだ決めない、などを選べる。選ぶと仕事・給料・働き方への影響を一言で出す | `PackApp.tsx` の `LifeEvents` |
| 会話の向き | 人物の絵を斜め向き（右向き）に描き直し、話す人が聞く人を向くように左右反転する | `public/packs/g1/` |
| 給料 | 求人原稿の書き方のまま出典つきで出し、その後は金額を出さず「上がりやすい・横ばい・下がることもある」で見せる | `src/lib/growth.ts` |
| 次に確かめること | 結果の最後に「未来を当てるのではなく、次に確かめることを見つける」と、面接で確かめる3つ | `src/lib/years.ts` の `CHECKS` |

### 職種ごとに見せ方を差し替える考え方

- 職場の種類（`place`：工場・オフィス・建設現場・物流・飲食）ごとに、背景の絵・場面の言葉・人物の役職を切り替えます。新しい職種は「背景の絵1枚＋場面の言葉」を足せば増やせます。
- Claude が読んだ求人は、いちばん近い職場の種類を選ばせ、その見本の求人をひな形にして中身（会社まとめ・知識・場面）だけを差し替えます（`registerAiRead`）。

### 90秒デモの5場面

1. 求人URLを入れる → 出典つきの会社まとめ（「不明」も出す）
2. 初期の3年で、知識が育つ
3. 1年・5年に切り替える
4. 6本の道から1本を選ぶ → Claude がその道の場面を作る
5. 「残る」と比べ、「未来を当てるのではなく、次に確かめることを見つける」で締める

## 画面の流れ（全案共通・求職者側）

1. 求人ページ（架空）→「入社後を試運転する」
2. 入力：選ぶだけの10問＋住むエリア
3. 会社を選ぶ：架空の2社（仮想 あおば社／仮想 みどり物流）
4. 試走中：5本の試走と、時点ごとの進み具合
5. 結果：時点ごとの出来事と分身の動き／能力表（8項目・S〜G）と理由／辞めたくなる度合い（高・中・低）と理由／分かれ道（1本は違う業界へ移る筋）／上司あり・なしの比べ表示／面接で確かめる質問
6. 2社に入った場合の比べ表示

各段階は URL の `#job` `#input` `#company` `#run` `#result` `#compare` で直接開けます（例：`/b#result`）。
デモ動画を撮る時は `?demo` を付けると、右下の説明窓（ⓘ）が出ません（例：`/a?demo#run`）。

## 守っていること

- 企業に合否・点数・％を出さない。「予測」ではなく「シナリオ（筋書き）」として見せる。
- 辞めたくなる度合いは「高・中・低」の3段階だけ。
- 能力表は人の格付けではなく、本人が選んだ目標にどこまで近づいたかとして出す。
- 実在の人名・会社名は使わない（すべて架空）。他社のゲーム作品名・キャラクターも使わない。
- 企業側の入力画面は今回は作らない（会社データは JSON で用意）。

## 動かし方

Node.js 20.9 以上が必要です。

```bash
npm install
npm run dev
# → http://localhost:3000 を開く（/a 〜 /j）
```

本番と同じ形で確かめる時：

```bash
npm run build
npm start
```

## 作り

- Next.js 16（App Router）＋ TypeScript ＋ Tailwind CSS 4
- `src/data/mirai.json` … 全案共通の見本データ（求人・10問・2社・5本の試走・時点ごとの結果・分かれ道・比べ表示）
- `src/lib/mirai.ts` … 画面の流れと入力の状態（全案共通）
- `src/app/a` 〜 `src/app/j` … 各案の画面
- `src/lib/life.ts` … H・I・J案共通の見本データ（求人5件、生涯の筋書き、分かれ道6種）と画面の流れ
- `src/components/life/parts.tsx` … H・I・J案共通の部品（求人一覧・分身づくり・能力表・分かれ道・人生の並べ表示）
- `src/lib/art.tsx` … 絵の差し替え口。`ART` に「絵の名前 → 画像URL」を足すと、その場面の絵が画像に置きかわる
- `src/components/InfoWindow.tsx` … 説明窓（ⓘ）。この画面／項目の理由／機能一覧／メモ。項目を押すと画面の該当部分が光る
